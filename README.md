# pomentum.github.io

The Pomentum organisation's landing page, published at <https://pomentum.github.io/>.

Plain HTML and CSS, no build: edit `index.html` and `style.css`, push to `main`, and the
`pages` workflow publishes them. Preview locally with `python -m http.server 8000`.

Each project has its own site under this address, published from its own repository
(for example <https://pomentum.github.io/graphos/> from `pomentum/graphos`). A card on the
landing page links to it and uses the project's own README tagline, nothing more.
